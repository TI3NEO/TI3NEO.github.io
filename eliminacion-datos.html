Control y eliminación de datos

Información para consultar o solicitar ayuda sobre eliminación de información relacionada con aplicaciones de TI3NEO.

TI3NEO · Información pública

1. Información en tu teléfono

Cuando los datos se almacenan únicamente en un dispositivo, puedes revisar dentro de cada aplicación si incluye una opción de eliminación o restablecimiento. En Android también puedes ir a Ajustes → Aplicaciones → [nombre de la app] → Almacenamiento → Borrar datos cuando el dispositivo ofrezca esa opción.

Atención: borrar datos locales puede eliminar ajustes, mensajes, progreso y clasificaciones; revisa si necesitas conservar copias antes de hacerlo. La disponibilidad y el efecto exacto de estas funciones se verificarán para cada versión final.

2. ACOMPANA

La edición prevista para Google Play intercambia mensajes entre dispositivos vinculados de una familia mediante Wi-Fi local. Por ello, una copia de un mensaje podría permanecer en otro dispositivo familiar. Para obtener instrucciones de eliminación, envía un correo con el asunto Eliminación de datos ACOMPANA sin incluir información sensible de niños.

Solicitar orientación para ACOMPANA →

3. BLOCKRAT

Para consultar cómo eliminar configuraciones, registros de evaluación y clasificaciones almacenados localmente, escribe con el asunto Eliminación de datos BLOCKRAT. No envíes historiales de llamadas completos ni números de terceros.

Solicitar orientación para BLOCKRAT →

4. Si una futura aplicación incorpora cuentas

Si alguna aplicación permite crear cuentas en un servidor, TI3NEO deberá ofrecer un procedimiento operativo para solicitar la eliminación de la cuenta y datos asociados desde dentro de la app y desde esta web. La aplicación deberá gestionar efectivamente las solicitudes; un correo de contacto o una página web no sustituyen el borrado real. Si existe una suscripción, su cancelación puede requerir una acción independiente en Google Play.

5. Solicitudes y verificación

Para solicitudes relacionadas con datos que TI3NEO pudiera administrar, escribe a ti3neo@gmail.com e indica únicamente el nombre de la aplicación y la naturaleza de la solicitud. Antes de proporcionar instrucciones específicas, podremos pedir una verificación proporcionada para evitar acceso no autorizado. No envíes contraseñas ni datos sensibles.

Las funciones y pasos definitivos se ajustarán a la versión publicada de cada aplicación.

Contacto oficial TI3NEO

Para consultas relacionadas con aplicaciones, privacidad y soporte, escribe a ti3neo@gmail.com. No envíes contraseñas, nombres de niños, registros de llamadas completos ni otra información sensible por correo.
